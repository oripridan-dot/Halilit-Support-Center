## Technical Details

### Format

- **Type:** glTF 2.0 Binary (GLB)
- **Compression:** Draco mesh compression (level 7)
- **PBR Materials:** Full PBR with metalness and roughness
- **Texture Maps:** Baked into vertex colors for web optimization

### Compression Stats

- **Raw file size:** ~5.8 MB (all files combined)
- **Compressed size:** ~1.8 MB (all files combined)
- **Compression ratio:** 69% smaller
- **Individual reduction:** 80-82% per file

### Loading Performance

- **Parse time:** 50-200ms per file (depends on connection)
- **Memory footprint:** ~50-100 MB (all assets loaded in Three.js scene)
- **Render performance:** 60+ FPS on modern devices (GPU-accelerated)

## Integration with Frontend

### How Models Are Loaded

The `Environment3DRenderer` automatically loads models from this directory:

```typescript
// In environment-config.ts
const guitarEnvironment = {
  sceneElements: [
    {
      type: 'model',
      modelPath: 'models/guitars/electric/stratocaster.glb',
      position: [0, 0, 0],
      scale: [1, 1, 1]
    }
  ]
}

// In Environment3DRenderer.ts
async loadAssets() {
  const gltf = await this.gltfLoader.loadAsync(modelPath)
  // Draco compression automatically decompressed
  // PBR materials automatically applied
  scene.add(gltf.scene)
}
```

## Customization

### Color Variants

To create color variations, regenerate with modified script:

```python
# In blender_asset_generator.py, edit create_electric_guitar():
body_material = self.create_material(
    "Guitar_Body",
    (0.8, 0.4, 0.0),  # Change to orange, blue, black, etc.
    metalness=0.6,
    roughness=0.3
)
```

Then regenerate:

```bash
blender --background --python blender_asset_generator.py
```

### Adding New Models

1. Create new method in `BlenderAssetGenerator` class
2. Add to `generate_all_assets()` list
3. Regenerate all assets
4. Update environment config to reference new model

See `BLENDER_ASSET_GENERATOR_GUIDE.md` for detailed instructions.

## Troubleshooting

### Models Not Loading

1. **Check file exists:** `ls -la models/guitars/electric/`
2. **Check path in config:** Verify path matches exactly
3. **Check browser console:** Look for 404 or parse errors
4. **Verify Draco support:** Most modern browsers supported

### Poor Visual Quality

1. **Increase compression level:** Edit `draco_mesh_compression_level=5`
2. **Regenerate:** `blender --background --python blender_asset_generator.py`
3. **Clear cache:** Hard refresh browser (Ctrl+Shift+R)

### Large File Sizes

1. **Increase compression:** Set `draco_mesh_compression_level=10`
2. **Reduce polygon count:** Simplify model geometry in Blender
3. **Regenerate:** `blender --background --python blender_asset_generator.py`
