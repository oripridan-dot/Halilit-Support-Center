# Evolution Proposals

This directory holds **Scout Evolution Proposals** — Markdown reports generated by the Scout Agent (`backend/factory/scout_agent.py`) after scanning the AI tool landscape.

## How it Works

1. Run `python factory.py scout` to trigger the Scout cycle.
2. The Scout writes timestamped proposal files here (e.g. `2026-02-20_mcp_data_cache.md`).
3. On the next Chief startup, all proposals in this directory are injected into the Chief's context.
4. The Chief acts as the **Genetic Guardian**: it approves tools that align with `master_plan.md` and ignores the rest.

## Proposal Lifecycle

| Status      | Meaning                                                    |
| ----------- | ---------------------------------------------------------- |
| `RECOMMEND` | Chief should schedule a Task Force to integrate this tool. |
| `MONITOR`   | Worth checking again in 30 days. Do not act yet.           |
| `SKIP`      | Actively misaligned with the Master Plan. Archived only.   |

## Naming Convention

```
YYYY-MM-DD_proposal_id.md
```

## Important

- The Scout **never** modifies code. It only writes proposals.
- A proposal is not a commitment. Only a Chief-approved `task_force` makes changes.
- See `specs/strategy/master_plan.md → Evolution Protocol` for the full governance model.
