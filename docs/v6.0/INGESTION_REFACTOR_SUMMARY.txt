📊 UNIFIED DATA MODEL: IngestionProductDraft
───────────────────────────────────────────────────────────────────────────

A single object flows through all 6 phases, accumulating enrichments:

IDENTITY:
  halilit_id, product_name, official_name, brand, model_number, sku

TAXONOMY:        (Populated in Phase 2)
  canonical_category, canonical_subcategory, brand_taxonomy, keywords

PRICING:         (Populated in Phase 3)
  price_il, price_eilat, tier, eilat_discount%, price_usd, price_eur, etc.

DISPLAY:         (Populated in Phase 4)
  display_role, hero_image, media_assets, display_tier_level, color_hint, etc.

CONTENT:
  description_short, description_long, feature_list, specifications

SOURCE:
  primary_source, sources[], source_confidence, extraction_metadata

QUALITY:
  data_completeness (0-1), quality_score (0-1), validation_status, errors

───────────────────────────────────────────────────────────────────────────

🔄 THE 6-PHASE PIPELINE
───────────────────────────────────────────────────────────────────────────

PHASE 1: HARVEST
  Input:  Raw dict from scraper
  Task:   Extract basic fields (id, name, prices)
  Output: IngestionProductDraft (minimal)
  Time:   ~1ms per product

PHASE 2: ENRICH - TAXONOMY
  Input:  Product name, brand, description
  Task:   Classify into universal taxonomy
  Output: IngestionProductDraft + taxonomy mapping
  Time:   ~2ms per product

PHASE 3: TIER - PRICING
  Input:  Price data
  Task:   Determine tier, validate, calculate discounts
  Output: IngestionProductDraft + pricing strategy
  Time:   ~1ms per product

PHASE 4: PREPARE - DISPLAY
  Input:  Tier, completeness, media assets
  Task:   Calculate display properties
  Output: IngestionProductDraft + display configuration
  Time:   ~2ms per product

PHASE 5: VALIDATE
  Input:  Complete product
  Task:   Check against all validation rules
  Output: IngestionProductDraft (validated) or rejected
  Time:   ~1ms per product

PHASE 6: APPROVE
  Input:  Valid product
  Task:   Mark as approved, generate report
  Output: IngestionProductDraft (APPROVED) in report
  Time:   ~1ms per product

TOTAL TIME: ~8ms per product (100+ products/sec)

✨ EXAMPLE USAGE
───────────────────────────────────────────────────────────────────────────

from backend.ingestion import get_ingestion_orchestrator

orchestrator = get_ingestion_orchestrator()

raw_products = [
    {
        "name": "Nord Lead A1",
        "price_il": 14500,
        "price_eilat": 12325,
        "source_url": "https://halilit.com/nord-lead",
    },
]

report = orchestrator.ingest_batch("Nord", raw_products)

# Results
print(f"✅ Approved: {report.approved_count}")
print(f"❌ Rejected: {report.rejected_count}")

for product in report.approved_products:
    print(f"\n{product.product_name}")
    print(f"  Category: {product.taxonomy.canonical_category}")
    print(f"  Tier: {product.pricing.tier.value}")
    print(f"  Display: {product.display.display_role.value}")
    print(f"  Completeness: {product.data_completeness:.0%}")

# Issues
for product, errors in report.rejected_products:
    print(f"\n❌ {product.product_name}")
    for error in errors:
        print(f"  {error}")

# Recommendations
for rec in report.recommendations:
    print(f"💡 {rec}")
